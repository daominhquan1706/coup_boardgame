# Role Card Assets

Naming contract for each role folder:

- `card_front.png`: primary full-card artwork used by the app now
- `reserve_01.png` ... `reserve_08.png`: reserved future slots for alternate role visuals

Folders must match each role `firestoreValue` exactly:

- `duke`
- `assassin`
- `contessa`
- `captain`
- `ambassador`
- `inquisitor`
